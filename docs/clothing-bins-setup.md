# 트임 — 헌옷수거함 찾기 데이터·배포 설정

## 적용 경로
- `/clothing-bins.html`: 현재 위치 허용 / 동네명 수동 검색 / 1·3·5·10km 검색 반경 / 출처 표시 / 카카오맵 길찾기
- `/api/clothing-bins?lat=37.5&lng=127.0&radius=1000`: 거리순 조회
- `/api/clothing-bins?query=서울특별시 송파구`: 공식 CSV의 지역·주소·상세위치 키워드 조회
- `/api/clothing-bins/geocode?query=잠실동`: 카카오 REST 키 설정 시 좌표 변환
- 기존 홈의 더 둘러보기, `test.html#clear` 의류·신발 카드 및 `space.html`에서 진입 가능.

## 실제 수거함 자료 등록 (반드시 필요)
공공데이터포털 [전국의류수거함표준데이터](https://www.data.go.kr/data/15139214/standard.do)는 CSV로 공개됩니다. 전국 등록 지자체 자료이지, 모든 실제 수거함을 빠짐없이 담은 실시간 데이터가 아닙니다.

1. 공식 페이지에서 전국 표준 CSV 파일을 다운로드합니다.
2. UTF-8 CSV 파일을 프로젝트의 `public/clothing-bins-data.csv`로 추가합니다. 원래 표 머리글을 유지합니다. 예: `설치장소명,시도명,시군구명,소재지도로명주소,소재지지번주소,위도,경도,상세위치,관리기관명,데이터기준일자`.
3. 변경 파일을 커밋하고 Worker를 다시 배포합니다. `public`에 등록된 CSV는 공공데이터이므로 사용자에게 다운로드될 수 있습니다. 사용자의 현재 위치나 검색기록을 CSV에 기록하지 않습니다.

대안: Cloudflare Worker 비밀/환경변수 `CLOTHING_BINS_DATA_URL`에 **실제 검증된 공공데이터 다운로드 CSV 또는 JSON URL**을 설정합니다. 임의의 URL은 막으며 현재 지원하는 호스트는 data.go.kr, api.data.go.kr, apis.data.go.kr 및 api.odcloud.kr 계열입니다. 서비스키가 필요한 승인된 API 주소를 사용하는 경우 `DATA_GO_KR_SERVICE_KEY`(비밀변수)를 설정할 수 있습니다. **서비스키만 설정해도 자동으로 CSV가 연결되는 것은 아닙니다.** 공공데이터포털 목록 페이지 URL 자체는 데이터 다운로드 URL로 사용할 수 없습니다.

## 카카오 옵션
Cloudflare 비밀변수 `KAKAO_REST_API_KEY`를 설정하면 백엔드에서만 Kakao Local API를 호출합니다. 브라우저에 키를 삽입하지 마세요.
- GPS 허용 시: 공공데이터 근처 위치 + 카카오에 실제 장소로 등록된 의류수거함 검색 결과를 출처별로 구분합니다.
- 수동 주소 검색 시: 카카오 지오코딩이 활성화되면 반경 검색 후 거리순 표시. 없으면 공식 CSV의 주소 텍스트를 검색합니다.
- 카카오에 없는 수거함은 공공 CSV 좌표로 카카오맵 길찾기를 연결합니다.
- 키/CSV 모두 없는 경우 검색 결과를 만들어내지 않고 설정 미완료와 외부 카카오맵 검색 링크를 노출합니다.

## 배포
GitHub `main`을 실제 Cloudflare 인증 프로젝트에 동기화한 뒤 `npx wrangler deploy` 명령을 실행합니다. 이 리포지토리는 `wrangler.toml`에서 Worker `teim`, 엔트리 `_worker.js`, 정적 자산 `./public`을 사용합니다. GitHub 커밋 또는 병합 자체가 실서버 배포 성공을 보증하지 않습니다.

## 확인 항목
1. `/clothing-bins.html` 접속 후 GPS를 허용하면 위치 좌표를 검색에만 사용합니다(정확한 위치 좌표를 localStorage에 저장하지 않음).
2. 1km 결과가 없으면 3km, 5km로 자동 확대합니다. 버튼으로 10km도 선택 가능합니다.
3. GPS 거부/타임아웃 시 지역명 검색은 항상 가능해야 합니다.
4. 공공 CSV를 제공하지 않은 경우 `DATA_NOT_CONFIGURED`를 반환해야 합니다. 존재하지 않는 수거함을 표시하지 않습니다.
5. 자료가 제공된 경우 응답의 `source`에 따라 지자체 공개자료/카카오맵 등록 장소가 표시됩니다. 직선거리이며 배출 전에 설치 상태를 확인하도록 안내합니다.
6. 기존 성향테스트, 공간테스트, 트임 AI, 트임타임, 14일 사진 기록 기능은 유지됩니다.

## 개인정보
위치권한은 사용자가 버튼을 누를 때만 요청합니다. 위치 좌표를 사용자 로컬 기록에 저장하지 않으며, 조회 API의 응답은 `Cache-Control: no-store`로 제공됩니다. 좌표는 근처 장소 검색 처리에 사용됩니다. 일반적인 서비스 운영 로그와 외부 API 전송 정책은 Cloudflare/카카오의 별도 설정을 검토해야 합니다.
