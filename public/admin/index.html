트임 콘텐츠 관리

관리자 로그인 연결을 확인하고 있습니다.

관리 화면 준비는 끝났습니다. 최초 한 번, GitHub 로그인 연결이 필요합니다.

  1. GitHub OAuth 앱 만들기
    이름: TEUM Content Manager
    Homepage URL: https://teim.merry4008.workers.dev
    Callback URL: https://teim.merry4008.workers.dev/api/cms/callback
  2. Cloudflare → Workers & Pages → teim → Settings → Variables and Secrets에 추가:
    CMS_GITHUB_CLIENT_ID: Client ID
    CMS_GITHUB_CLIENT_SECRET: Client secret (Secret 유형)
  3. 변경사항을 배포한 뒤 아래 버튼을 눌러주세요.

비밀키는 채팅이나 GitHub 파일에 붙여넣지 말고 Cloudflare에 입력해주세요.
